# BCNESA Results Import Performance Plans

This folder contains the performance analysis and optimization roadmap for:

- `BcnesaPlayerAndResultsInitialImportService.processForSeason(baseFolder, season)`

## Files
- `EXECUTIVE_SUMMARY.md`
  - Short version for quick decision making.
- `PERFORMANCE_ANALYSIS_BCNESA_RESULTS_IMPORT.md`
  - Deep dive into DB IOP, CPU, memory, and I/O bottlenecks with code references.
- `PHASED_OPTIMIZATION_PLAN.md`
  - Step-by-step plan to reduce IOPs and runtime safely.

## Recommended reading order
